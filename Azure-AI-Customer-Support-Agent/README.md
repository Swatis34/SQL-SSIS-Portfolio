# Azure AI Customer Support Agent

## 📌 Project Overview

This project demonstrates a hands-on Generative AI use case built using Azure AI Foundry.

The project focuses on creating and configuring a customer support AI agent, providing FAQ-based information, testing the agent through the Playground, and exploring customer segmentation using manually provided sample customer data.

## ⚙️ Key Implementation Steps

1. Created an Azure AI Foundry project.
2. Created and configured a Customer Support Agent.
3. Defined instructions for the agent to handle customer-support queries.
4. Provided customer support FAQ information for the agent to use while responding.
5. Tested the agent using the Azure AI Foundry Playground.
6. Provided sample customer data manually for testing.
7. Explored customer segmentation based on the manually provided customer data.
8. Reviewed and tested the generated responses and segmentation results.

## 💬 Customer Support Use Case

The agent was configured and tested for customer-support scenarios using the provided FAQ information.

Example areas included:

- Customer queries
- Product/service-related questions
- FAQ-based responses
- Customer-specific questions based on provided sample data

## 📊 Customer Segmentation

A sample customer dataset was manually provided to the AI agent for experimentation.

The project explored how an LLM-based application can analyze customer information and generate customer segmentation based on the provided data.

> Note: The customer segmentation data was provided manually for this hands-on experiment and was not directly connected to a SQL database.
